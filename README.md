# Enerplus Resources Website

A static, multi-page website for Enerplus Resources. It includes company information, wholesale products, sustainability, careers, and contact details.

## Pages

- `index.html` — Home page with a featured selection from the wholesale product catalog
- `company.html` — Company information
- `operations.html` — Wholesale product catalog and category filters
- `sustainability.html` — Sustainability information and report details
- `careers.html` — Careers and searchable job listings
- `privacy-policy.html` — Privacy policy

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve the project directory with a local static file server. Keep the `assets` directory alongside the HTML files so images and documents load correctly.

## Shared files

- `style.css` — Site-wide layout, responsive styles, and page-specific styling
- `script.js` — Mobile navigation, chat popover, careers search, and product filtering
- `assets/` — Images and the available sustainability report PDF

## Contact and forms

Contact and order links use `mailto:` links. The chat popover also opens an email draft addressed to `info@enerplusresources.com`; it does not submit to a server or send email directly. Job application links on the careers page open email drafts addressed to `info@enerplusresource.com`.
